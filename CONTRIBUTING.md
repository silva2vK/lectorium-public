# Contribuindo

O Lectorium é um produto de código fechado. Este repositório público existe para distribuição, documentação e acompanhamento das versões publicadas.

O código-fonte principal do Lectorium não é distribuído aqui e não recebemos contribuições de código por pull request.

Se você encontrou um problema, tem uma sugestão, quer propor uma melhoria ou entrar em contato sobre o projeto, envie um e-mail para:

**contato@lectorium.com.br**

Ao relatar um problema, inclua sempre que possível:

- uma descrição clara do que aconteceu;
- passos para reproduzir o problema;
- comportamento esperado e comportamento observado;
- versão do Lectorium utilizada;
- dispositivo, sistema operacional ou navegador;
- capturas de tela ou vídeos que ajudem a demonstrar o problema.
