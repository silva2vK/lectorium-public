# Contribuindo

O Lectorium é um produto de código fechado. Este repositório hospeda apenas o
wrapper Android (TWA) de distribuição — não há código-fonte do produto aqui e,
por isso, não recebemos contribuições de código.

Se você encontrou um bug no app Android ou tem uma sugestão, abra uma
[issue](../../issues). Relatos com passos para reproduzir, versão do
Android/dispositivo e prints ajudam bastante.
